# GeneCraft - Module 1: CRISPR Puzzle

A C program that simulates DNA editing as a puzzle.
DNA is stored as a C string. The player uses Replace, Cut and
Insert to turn faulty DNA into the healthy target within a move limit.
This is a simulation, not real laboratory CRISPR.

## Run
gcc crispr_puzzle.c -o crispr_puzzle
./crispr_puzzle
